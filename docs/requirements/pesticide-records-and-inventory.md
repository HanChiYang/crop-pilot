# 資材施用與農藥庫存

## 已確認的首版範圍

農民完成資材施用後，可從桌機版作物栽培管理查詢、新增、編輯或刪除作業。已結束的栽培可從歷史詳情補登，填寫實際施用日期，栽培維持「已結束」。

同一次作業共用一個實際施用日期，可同時登記農藥和肥料，以及噴施和撒施。每筆明細選擇資材類別、資材、批次和施用方式，依批次的庫存單位填寫實際用量。同一資材用到多個批次時，各批次分開填寫。

有噴施明細時可選填「噴施總水量」，以公升記錄本次所有噴施明細共用的水量。全為撒施時留空。編輯時若移除最後一筆噴施明細或將它改為撒施，表單清除原噴施總水量。

這次透過農藥庫存 API 建立主檔、登記期初庫存與進貨批次，以及查詢各批次餘量。桌機的農藥庫存管理畫面列入後續切片。主檔設定庫存單位，液態可用公升或毫升，固態可用公斤或公克。進貨量、期初量、批次餘量與實際施用量沿用該資材的庫存單位。

庫存明細顯示各批次的登記量、剩餘量、每庫存單位的進貨單價，以及整批進貨金額。整批進貨金額以進貨量乘以單價計算。期初庫存若無已知成本，可留空。

資材施用紀錄和庫存餘量一起更新。新增按批次扣量，編輯用量或更換批次時按差異調整。確認刪除整筆作業後，各筆用量退回原批次。

## 驗收條件

| 情境 | 預期結果 |
| --- | --- |
| 透過 API 建立農藥主檔，分別登記期初庫存和進貨 | 庫存可查詢各批次的餘量，兩種來源的批次都可在資材施用表單手動選取。 |
| 液劑以 40 公升進貨，每公升 NT$350；粒劑以 20 公斤進貨，每公斤 NT$280 | 批次明細各自使用公升、公斤顯示登記量、餘量和單價，並分別顯示整批進貨金額 NT$14,000 和 NT$5,600。 |
| 登記成本未知的期初庫存 | 批次可儲存和扣量，單價與整批金額顯示為未填。 |
| 同一次作業使用農藥 A 的兩個批次，以及農藥 B 的一個批次 | 儲存後清單顯示一筆作業及三筆明細，各批次按各自的實際使用量扣除。 |
| 同次作業噴施兩種農藥、撒施一種粒劑 | 儲存為一筆作業與三筆明細。各明細顯示施用方式，噴施總水量以公升記一次，各批次按農藥用量扣除。 |
| 噴施總水量留空，或整筆作業全為撒施 | 皆可儲存，水量顯示未記錄或不適用。全為撒施時，表單不提供水量輸入，API 拒絕帶水量的請求。 |
| 編輯混合作業並移除最後一筆噴施明細，或將它改為撒施 | 表單清除噴施總水量，儲存後原水量為空。庫存依各明細的批次及用量變動調整。 |
| 從已結束栽培的歷史詳情補登 | 新紀錄歸在該栽培並保留實際作業日期，所選批次扣量，栽培維持「已結束」。 |
| 編輯用量或更換批次 | 原批次退回應退用量，新批次或同批次同步扣除應扣用量。 |
| 刪除整筆作業 | 取消確認時保留紀錄與餘量。確認成功後，紀錄從清單移除，各筆用量退回原批次。 |
| 任一批次餘量不足，例如餘量 20 mL 卻輸入 30 mL | 提示有問題的明細，保留表單輸入。整筆儲存失敗，所有批次餘量維持原值。 |

## 資材施用整合提案

在同一張資材施用表單內登記農藥與肥料。同一桶配液可包含兩種農藥和一種葉肥，記為一筆作業、三筆資材明細及一個噴施總水量。各筆明細選擇各自的庫存批次並登記實際用量。任何批次餘量不足時，保留表單輸入且整筆不扣量。

已確認的登記規則是，同一天、同一栽培批次使用兩桶不同配液時，可分開登記為兩筆作業。每筆各自保存資材明細和噴施總水量，歷史清單能分別查詢與編輯。

驗收情境為在同一栽培批次及作業日先登記一桶含兩種農藥與一種葉肥的配液，再登記另一桶不同配液。儲存後顯示兩筆作業，每筆只顯示該桶資材及水量，各批次按兩筆作業各自登記的用量扣除。
