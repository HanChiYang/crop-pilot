# CropPilot｜採收、販售與栽培損益需求草案

## 使用情境

農民在桌機上記下每次採收、透過農會或自行販售的收入，以及種苗、資材、人工和委託農機等費用。忙碌時可先登記交貨或結算金額，有需要再補採收與分攤明細。從農場損益可查一段期間整體賺多少，從栽培詳情可查某一批作物的採收及累計收支。

## 已確認的首版方向

### 採收

- 每一筆採收屬於一個栽培批次。同一批作物可以分多次採收，各次記實際採收日、公斤重量和選填備註。
- 農友可以先記出貨，再補登採收。出貨時若已知來源，可先選栽培批次。

### 販售與農會結算

- 販售通路涵蓋農會與自行販售。自行販售首版以公斤計價，填販售重量及每公斤單價，自動計算總額。
- 一筆農會出貨可合併多個栽培批次，也可包含多筆等級或大小規格明細。同一等級可以來自不同批次。出貨前已知分級資料時可先記錄，交貨後才收到資料時可補填。
- 交貨後可以先存為「待結算」。最後應得貨款淨額一經確認，可改為「已結算」並計入損益。已成交且金額仍待確認的交貨維持待結算。
- 結算可登記整筆淨額。有明細時可保存各列等級、規格、數量與單價，以及結算扣款。首版由農友手填各栽培批次的分攤金額，可當下填、日後補做或略過。依同級重量試算分攤留待後續。
- 農會收入可以只分攤已知的部分。未分攤收入為結算淨額扣除已分攤金額，日後可繼續補登。分攤後的各批金額與未分攤收入合計須等於結算淨額。
- 已記來源的出貨可查回相應栽培批次，從栽培詳情也可反查出貨。已結算淨額全數計入農場收入，單批損益只計入已歸屬該批的收入。同一筆收入在農場合計中只計一次。

### 栽培成本

- 成本涵蓋種苗、用藥、施肥、人工、包裝材料、委託農機作業等。用藥和施肥沿用既有的資材施用紀錄，以實際用量乘以明細保存的批次單價。單價缺漏的施用成本顯示「待補」。[資材施用設計](../design/first-desktop-slice-data-api.md#資材施用)
- 人工、包材、農機等支出可按實際費用記錄。多批共用的費用可以只記一筆，並選擇是否分攤到各栽培批次。農場總成本扣整筆費用一次，單批損益扣已歸屬該批的金額。

### 損益與桌機入口

- 左側主選單新增「農場損益」。依選定的日期區間顯示已確認收入、已記成本及損益。已結算但未分攤的收入，以及未分攤的成本，都計入農場合計並可查到來源紀錄。
- 農會收入依結算確認日歸入農場損益期間。出貨時可另記交貨日，後續入帳日期不影響收入歸期。
- 單批栽培損益放在栽培詳情。進行中的批次從「作物栽培」進入，已結束的批次從「栽培紀錄」進入。詳情顯示該批採收、販售、成本及累計損益。
- 有關聯出貨或費用尚未分攤時，栽培詳情提示損益仍有未分攤項目。有待結算收入或待補成本時，也顯示相應狀態。

### 栽培批次刪除

- 栽培批次已有採收、販售或手動成本紀錄時，拒絕整批刪除。販售包含已記該批為來源的待結算出貨，手動成本包含該批已分攤的共用費用。畫面提示阻擋原因，農友可更正相關紀錄，或將該批栽培結束以保留歷史。
- 誤建的栽培批次若無上述紀錄，沿用整批刪除流程。批次已有資材施用時，確認畫面列出作業筆數、各原庫存批次的恢復用量及將移除的已知施用成本。有未知單價的施用明細時提示成本資料缺漏。確認刪除後退回用量，農場損益同步移除這些施用紀錄產生的成本。實際已完成的栽培可改為「已結束」以保留歷史。[整批刪除 UX 審查記錄](../prototype-plan.md#ux-草案審查記錄)

## 驗收草案

| 情境 | 可觀察的結果 |
| --- | --- |
| 同一批番茄在兩天分別採收 40 公斤與 60 公斤 | 栽培詳情可查到兩筆採收，各自保留日期與數量。 |
| 北側田與南側田的番茄同次交給農會，當下尚無單價，部分採收也尚未登記 | 可儲存一筆「待結算」出貨並保存已知來源。農場可見該筆出貨，已確認收入暫不增加。採收可日後補登。 |
| 同一次出貨按等級結算，特級 50 公斤每公斤 NT$80、優級 25 公斤每公斤 NT$40，扣款 NT$300 | 顯示銷售總額 NT$5,000、淨額 NT$4,700。確認結算後農場收入增加 NT$4,700。 |
| 11 月 30 日交貨，12 月 2 日確認結算淨額，12 月 4 日收到款項 | 11 月的已確認收入不含這筆貨款。這筆收入列在 12 月 2 日，並納入 12 月農場損益。 |
| 上述結算先略過分攤，日後依序補登北側田 NT$2,800、南側田 NT$1,900 | 略過時未分攤收入為 NT$4,700，已知來源的批次看得到該筆出貨。只填北側田時，北側田收入增加 NT$2,800，未分攤收入剩 NT$1,900。補登南側田後，兩批顯示各自收入，未分攤收入歸零。農場收入全程維持 NT$4,700。 |
| 上述結算已分攤北側田 NT$2,800，再填南側田 NT$2,000 | 顯示分攤總額超過結算淨額，保留表單輸入。已儲存的分攤和兩個損益入口的金額維持原值，改填 NT$1,900 後可儲存。 |
| 上述出貨的特級明細中，北側田供應 30 公斤、南側田供應 20 公斤 | 從特級明細可查到兩個來源及各自重量，也可從任一栽培批次反查該筆出貨。 |
| 自行販售 10 公斤番茄，每公斤 NT$100 | 販售總額為 NT$1,000，納入農場損益，通路顯示自行販售。 |
| 委託農機共花 NT$6,000，先略過分攤，之後分給北側田 NT$3,500 與南側田 NT$2,500 | 兩批的成本按分攤更新，農場總成本始終只計入 NT$6,000。 |
| 使用單價為每公斤 NT$20 的肥料 3 公斤，以及一批單價未知的農藥 | 已知施肥成本增加 NT$60，農藥明細標示「成本待補」，損益摘要提示成本資料缺漏。 |
| 已確認收入為 NT$5,700，已記成本為 NT$4,200 | 農場期間損益顯示 NT$1,500。切換到其他期間時，摘要及明細依選定期間更新。 |
| 嘗試刪除已有採收、關聯販售或手動成本的栽培批次 | 顯示阻擋原因，栽培與關聯紀錄仍可查詢，農場和單批損益金額不變。把批次改為「已結束」後，可從栽培紀錄查看該批資料。 |
| 誤建批次只有一筆施肥，使用單價每公斤 NT$20 的肥料 3 公斤 | 刪除預覽顯示原庫存批次將恢復 3 公斤，並將移除 NT$60 施肥成本。取消時保留紀錄、庫存與成本。確認後移除栽培及施肥紀錄，原批次恢復 3 公斤，施肥所在期間的農場成本減少 NT$60。 |

## 待確認事項

- 農場期間報表的其他日期基準。提案以自售販售日、支出發生日及資材施用日分別彙總。
- 採收損耗量與分級的登記方式。農會出貨已確認可在出貨或結算時記分級。

## UX 交接

沿用現有 CropPilot Figma 設計檔，在「桌機｜開發中」分頁依下列區塊審查。

| 區塊 | 審查範圍 |
| --- | --- |
| 1. 栽培詳情與採收 | 由「作物栽培」及「栽培紀錄」進入詳情。走查採收清單、新增採收及同批分兩天採收，並確認販售、成本與累計損益的位置。 |
| 2. 自行販售 | 填日期、公斤數及每公斤單價，確認系統計算的總額後儲存。 |
| 3. 農會出貨與結算 | 多批合併出貨、待結算、補填分級與淨額、略過或部分分攤，以及追查來源批次。 |
| 4. 栽培成本 | 新增手動費用、選填共用費用分攤，查看從資材施用帶入的成本及缺漏提示。 |
| 5. 農場與單批損益 | 從左側「農場損益」按期間查收支，從栽培詳情查單批累計損益及待補項目。 |

第 1 區塊依確認的靜態稿實作。詳情顯示採收、販售、成本及累計損益四個頁籤，首批提供採收操作，其餘頁籤顯示開發中。農場損益提供跨批次販售與費用的登記入口，栽培詳情可回查與該批有關的紀錄。北側田與南側田的番茄沿用同一組示意資料。[Figma 栽培詳情與採收靜態稿](https://www.figma.com/design/BwXm9ifVg4hZyteraSpuvc/CropPilot?node-id=574-2)

農會先交貨再確認價格的情境參考[美濃區農會共同運銷手冊](https://www.meinong.org.tw/Uploads/Document/DM/637557488963146383.pdf)。分級配送及共同計價參考[農糧署燕巢番石榴案例](https://crb.afa.gov.tw/index.php?article_id=11360&code=list&flag=detail&ids=16)與[北農番茄分級規格](https://www.tapmc.com.tw/Pages/Market/Packing/G0005F)。
