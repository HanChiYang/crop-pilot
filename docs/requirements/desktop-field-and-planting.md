# CropPilot｜桌機版田區與栽培管理需求草案

田區與栽培進入資料庫與 API 設計。Google 登入已加入桌機原型，並確認首登建帳規則與後端套件。

## 使用者提出的能力

| 編號 | 農民可以做到的事 |
| --- | --- |
| R1 | 從未登入的首頁進入登入畫面，以 CropPilot 帳號密碼或「以 Google 帳號登入」進入田區總覽。 |
| R2 | 登入成功後進入田區總覽，看到全部田區及各田區的作物栽培狀況。 |
| R3 | 從田區總覽左側選單進入「田區管理」或「作物栽培管理」。 |
| R4 | 新增、編輯、刪除田區，並設定名稱、面積（平方公尺）、座標與備註。 |
| R5 | 選擇田區，新增、編輯、刪除該田區的一筆栽培紀錄，並設定作物、品種、栽種日期與備註。 |
| R6 | 在作物栽培管理中變更個別栽培紀錄的狀態，並在田區總覽看到「採收中」的作物。 |

「栽培紀錄」是這份草案對 R5 的暫稱，表示某塊田在某一次種了某個作物。若首版需要管理作物和品種清單，可在確認資料來源後定義。

## 已確認的首版規則

- 同一田區可同時有多筆栽培紀錄，例如同時種番茄和小白菜。
- 農民登入後查看自己的全部田區。首次登入沒有田區時，引導新增；田區目前沒有作物時，總覽仍列出該田區。登入流程包含登入失敗提示和登出。
- 新建本地帳號後，須通過一次性驗證碼（OTP）才可登入。第一次使用 Google 登入時，以已驗證且尚未對應既有 CropPilot 帳號的電子郵件自動建帳，並直接啟用。若電子郵件已有帳號，提示使用既有登入方式或完成原帳號待辦的 OTP 驗證。
- 新增田區時，名稱和面積（平方公尺）必填，座標及備註選填。只填名稱和面積即可建立田區。
- 每筆栽培紀錄可分別變更狀態。首版使用「規劃中 → 栽培中 → 採收中 → 已結束」，也可從「栽培中」直接轉為「已結束」。採收中表示已開始採收且栽培尚未結束。
- 田區總覽按田區顯示「規劃中」「栽培中」和「採收中」的作物。同一田區的多筆作物各自顯示狀態。
- 分開保存預定栽種日與實際栽種日。規劃中的預定栽種日可留空，有填時在總覽標示「預定栽種日」。進入「栽培中」時實際栽種日必填，由使用者輸入或修正。總覽有實際日期時優先顯示，並標示「實際栽種日」。
- 已結束的栽培紀錄保留，從目前栽培總覽收起。歷史列表、搜尋和跨季查詢排到後續。
- 田區只要有栽培紀錄（包含已結束的紀錄），首版禁止刪除並提示原因。沒有栽培紀錄的田區可刪除。
- 單筆栽培紀錄僅在「規劃中」可刪除。已進入「栽培中」「採收中」或「已結束」的紀錄保留。

## 參考產品

參考來源：[農務 e 把抓操作手冊](https://agrepm.moa.gov.tw/Front/Home/QuestionFile/287635)示範在耕地上新增栽培、記錄採收完畢後接續輪作。[Farmbrite 新增栽培](https://help.farmbrite.com/help/fields-crops)與[完成栽培](https://help.farmbrite.com/help/completing-plantings)將地點、作物及歷次栽培分開。[Farmable 田區設定](https://farmable.tech/help/en/articles/16066994-how-do-i-add-fields-in-the-web-portal)提供地圖圈選與多品種設定。地圖、排程與預計採收可另行評估。

## 驗收切片

1. **先跑通主流程**。首頁的兩個登入入口皆可進入登入畫面。以測試帳號登入，從空的田區總覽新增一塊田。只填名稱和面積可以儲存，田區管理顯示名稱和面積。填入座標時，儲存後也能看到座標。從作物栽培管理選這塊田，新增一筆「規劃中」紀錄，回總覽看到該田區和作物。驗收含登入失敗提示，以及栽培紀錄未填預定栽種日也能建立並出現在總覽。
2. **補齊管理流程**。同一田區建立兩筆栽培，把其中一筆改成「採收中」。總覽同時顯示一筆「採收中」與一筆「栽培中」。再結束前一筆，確認它從目前總覽收起且紀錄仍保留，另一筆仍顯示。編輯和刪除依已確認的規則驗收。

同一田區可在總覽同時看到規劃中和正在栽培或採收的作物。規劃中的紀錄有填日期時顯示「預定栽種日」，留空時仍顯示該紀錄。將規劃中的紀錄改為「栽培中」時，若實際栽種日空白，畫面提示必填且狀態維持原值。填寫實際栽種日後可完成變更，總覽改顯示「實際栽種日」。

Google 登入驗收涵蓋從登入頁跳到 Google、成功返回後只看到自己的田區、取消或失敗時回登入頁看到提示且能重試，以及登出後需重新驗證才能讀取田區。首次登入的帳號建立規則見 API 設計中的 Google 登入章節。[Google 登入設計](../design/first-desktop-slice-data-api.md#google-登入)

新增田區時，清空名稱或面積後送出，應在相應欄位看到必填提示，且不建立田區。

田區刪除驗收須涵蓋有栽培紀錄的田區、只有已結束紀錄的田區，以及沒有栽培紀錄的田區。前兩種應顯示禁止刪除的原因；第三種刪除後應從總覽移除。

刪除單筆栽培時，「規劃中」可刪除並從總覽移除，其他狀態應保留。
